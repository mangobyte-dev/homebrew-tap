# MangoByte Homebrew tap

```sh
brew install mangobyte-dev/tap/sweetui
```

`sweetui` installs source-owned SweetUI items from https://github.com/mangobyte-dev/sweetui into your app and keeps them updatable. Each formula version matches a release of that repository; the tap tag `sweetui-<version>` is what the tool's update notice reads. Before 0.5.0 the formula was `swiftui-registry`: `formula_renames.json` maps the old name, and each release also carries a `swiftui-registry-<version>` tag for 0.4.0 binaries.
