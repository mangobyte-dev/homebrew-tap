# MangoByte Homebrew tap

```sh
brew install mangobyte-dev/tap/swiftui-registry
```

`swiftui-registry` installs source-owned SwiftUI registry items from https://github.com/mangobyte-dev/swiftui-ui-registry into your app and keeps them updatable. Each formula version matches a release of that repository; the tap tag `swiftui-registry-<version>` is what the tool's update notice reads
